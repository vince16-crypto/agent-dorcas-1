Privacy Policy

Nia's Rhythm Room and its publishing tool Agent Dorcas 1
Last updated: September 28, 2026

What Agent Dorcas 1 is

Agent Dorcas 1 is a private tool used only by the owner of the Nia's Rhythm Room YouTube channel. It makes original children's music videos and uploads them to that one channel through the YouTube Data API. No one else signs in to it or uses it.

What data it uses

  • With the channel owner's permission (Google OAuth), it uploads videos, sets thumbnails, adds videos to playlists, and updates the channel's own description, keywords and banner.
  • It does not collect, store or process personal information about viewers, subscribers or children.
  • It does not read viewer comments, messages or analytics, and it does not use cookies or tracking.

Where access tokens are kept

The OAuth refresh token is kept as an encrypted secret in the owner's private GitHub repository. It is used only to call the YouTube Data API for this channel, and it is never shared with or sold to anyone.

Children's privacy

All videos are marked "Made for Kids" on YouTube, so YouTube turns off personalized ads, comments and other data features for them. Nia's Rhythm Room does not collect any information from children.

Google API Services User Data Policy

Agent Dorcas 1's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The channel owner can remove Agent Dorcas 1's access at any time at myaccount.google.com/permissions.

Contact

For questions about this policy, use the contact details on the Nia's Rhythm Room About page.
